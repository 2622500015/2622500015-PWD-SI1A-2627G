## Deskripsi Pertemuan-10
Pada pertemuan kesepuluh membahas Analisis Kebutuhan Data dan Dasar MySQL Satu Tabel.

### Materi yang dibahas:
1. **Menjalankan phpMyAdmin, dan Merancang Struktur Tabel MYSQL.**
2. **Membuat Basis Data, Tabel Menggunakan phpMyAdmin dan Perintah DDL Create Database dan Create Table.**
3. **Memasukkan, Memeriksa Data Awal dan Perintah SQL Insert.**
4. **Mengekspor Struktur dan Data Basis Data.**
### Tujuan Pembelajaran
- Membuka phpMyAdmin lalu membuat basis data, tabel dan mengisi struktur kolomnya
- Membuat dan menentukan nama basis data dan tabel, mengisi atribut sesuai dengan formulir kontak, tipe datanya serta mencari primary key dan a.i dari formulir tersebut dan memeriksanya kembali.
- Menggunakan fasilitas insert untuk memasukkan Data dan memeriksa data yang sudah dimasukkan di Browse.
- Mengekspor basis data ke format sql lalu menentukan pengaturan ekspor.
- Memerika kesesuaian data, memperbaiki memperbaiki ketidaksesuaian dan memeriksa berkas hasil ekspor.
