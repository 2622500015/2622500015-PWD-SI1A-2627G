## Deskripsi Pertemuan-04
Pada pertemuan keempat Membahas CSS3 Layout dan Responsive Web Design. 

### Materi yang dibahas:
1. **Memisahkan CSS dari dokumen HTML agar struktur HTML dan aturan styling dikelola secara terpisah.**
2. **Membuat Berkas style.css untuk menempatkan seluruh aturan CSS.**
3. **Menerapkan Box Model, Flexbox, Grid, dan Desain Web Responsif dengan Media Query.**
4. **Praktikum**
- Membuat CSS Box Model untuk Penataan Halaman, CSS Flexbox untuk Navigasi, CSS Grid untuk Tata Letak Utama, dan Desain Web Responsif dengan Pendekatan Mobile-First serta melakukan pengujian viewport.

### Tujuan Pembelajaran
- Mahasiswa mampu menerapkan CSS Box Model untuk mengatur ruang dan jarak elemen.
- Mahasiswa mampu menerapkan tata letak modern menggunakan Flexbox untuk navigasi dan CSS Grid untuk tata letak utama/main.
- Mahasiswa mampu menerapkan desain web responsif dengan pendekatan mobile-first menggunakan media query dan melakukan pengujian viewport.
