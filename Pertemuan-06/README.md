## Deskripsi Pertemuan-06
Pada pertemuan keenam mempelajari PHP Dasar dan Pemrograman Sisi Peladen.

### Materi yang dibahas:
1. **Menerapkan PHP Dasar untuk menghasilkan halaman web dinamis melalui peladen lokal.**
2. **Menggunakan variabel, konstanta, tipe data dasar, dan operator PHP.**
3. **Menerapkan percabangan dan perulangan PHP.**
4. **Praktikum**
- Menguji keluaran dinamis, percabangan, perulangan, mengidentifikasi galat debugging dengan localhost/Laragon, memperbaikinya, melakukan pengujian ulang serta mengelola kode dengan GitHub secara bertahap.

### Tujuan Pembelajaran
- Mahasiswa mampu menjelaskan cara kerja PHP sebagai bahasa pemrograman sisi peladen dan menjalankan skrip melalui peladen lokal.
- Mahasiswa mampu menggunakan sintaks dasar PHP, variabel, konstanta, dan tipe data dasar untuk menghasilkan keluaran dinamis.
- Mahasiswa mampu menerapkan operator aritmetika, perbandingan, logika, dan ternary untuk perhitungan dan pemeriksaan nilai.
- Mahasiswa mampu menerapkan percabangan if-elseif-else dan switch-case-default untuk menentukan keluaran berdasarkan kondisi.
- Mahasiswa mampu menerapkan perulangan for dan while untuk menampilkan data berulang.
- Mahasiswa mampu menerapkan fungsi bawaan PHP seperti number_format() dan date(), serta pemeriksaan nilai NULL.
