## Deskripsi Pertemuan-11
Pada pertemuan kesebelas membahas Analisis Kebutuhan Data dan Dasar MySQL Satu Tabel.

### Materi yang dibahas:
1. **Integrasi PHP dengan MySQL menggunakan MySQLi.**
2. **Membuat dan menguji Berkas Koneksi PHP-MySQL dan mengintegrasikan ke Halaman Utama.**
3. **Mengambil Data dari Basis Data, menampilkan Data Basis Data pada Halaman Web dan Mengekspor Basis Data dan Tabel Praktikum.**
### Tujuan Pembelajaran
- Mengimplementasikan koneksi PHP dengan MySQL menggunakan MySQLi melalui berkas koneksi yang
dapat digunakan kembali serta menangani kegagalan koneksi.
- Menjalankan kueri SELECT pada satu tabel dan mengambil hasil kueri menggunakan MySQLi untuk
kebutuhan operasi READ.
- Menyajikan data hasil SELECT pada halaman web dengan struktur keluaran yang sesuai serta menerapkan pengamanan keluaran HTML.
- Menguji koneksi, kueri SELECT , dan penyajian data, menangani kondisi galat atau data tidak tersedia, serta mengidentifikasi dan memperbaiki galat yang ditemukan
