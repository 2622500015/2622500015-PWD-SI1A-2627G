## Deskripsi Pertemuan-06
Pada pertemuan ketujuh mempelajari Pemrosesan Formulir dengan PHP, Validasi Sisi Peladen, dan PRG.

### Materi yang dibahas:
1. **Konsep metode GET atribut METHOD dan ACTION pada formulir HTML.**
2. **Membandingkan Metode GET dan POST dan mengubah formulir utama menjadi POST.**
3. **Validasi, Normalisasi, dan Sanitasi Data di Sisi Peladen.**
4. **Pengelolaan nilai formulir dengan Session dan Pola POST-REDIRECT-GET (PRG).**
4. **Praktikum**
- Menguji pengiriman dan pemrosesan data formulir menggunakan metode GET dan POST, melakukan Validasi, Normalisasi, dan Sanitasi data di sisi peladen menggunakan PHP, pengamanan keluaran dengan htmlspecialchars(), penggunaan session dan pola PRG, mengidentifikasi galat debugging dengan localhost/Laragon, memperbaikinya, melakukan pengujian ulang serta mengelola kode dengan GitHub secara bertahap.
### Tujuan Pembelajaran
- Mahasiswa mampu mengirimkan dan memproses data formulir menggunakan metode GET dan POST.
- Mahasiswa mampu melakukan validasi, normalisasi, dan sanitasi data di sisi peladen menggunakan PHP.
- Mahasiswa mampu mengamankan keluaran HTML menggunakan htmlspecialchars()
- Mahasiswa mampu mempertahankan data formulir dan pesan notifikasi menggunakan session.
- Mahasiswa mampu menerapkan pola Post-Redirect-Get (PRG) untuk mengurangi resiko pengiriman ulang formulir saat halaman dimuat ulang.
- Menguji hasil pemrosesan formulir, menangani kesalahan, dan mendokumentasikan pengembangan.
