## Deskripsi Pertemuan-01
Pada pertemuan kedelapan mengerjakan UTS Pemrograman Web Dasar.

### Materi yang dikerjakan:
- **Membuat project website bisnis/usaha yang mencakup HTML, CSS, JavaScript dan PHP.**
- **Proses Pengerjaan**
- Membuat kerangka awal dan struktur web menggunakan index.html. Menghubungkan index.html dengan style.css agar form tertata untuk mendesain dan mempercantik website menggunakan Box Model, Flexbox, Grid, dan Desain Web Responsif dengan Media Query. Menghubungkan dan menerapkan script.js untuk mengakses dan mengubah elemen DOM, menangani peristiwa pengguna menggunakan Event Listener, menerapkan Validasi Formulir Sisi Klien dan memberikan respon kepada pengguna. Menerapkan PHP Dasar untuk menghasilkan halaman web dinamis melalui peladen lokal, menggunakan Variabel dan konstanta, menggunakan metode POST untuk Validasi, Normalisasi, Sanitasi Data di Sisi Peladen, dan menggunakan Session dan Pola PRG untuk mengelola nilai formulir.

### Aktifitas Pengerjaan dan Kendala
- Dalam membuat kerangka awal dan struktur index.html belum ada masalah dan masih bisa dikerjakan dengan lancar, lalu menghubungkan dan menerapkan style.css untuk mendesain web mulai ada masalah mulai dari membuat layoutnya yang harus di coba satu persatu hingga menemukan yang cocok, lalu memasukkan background agar tidak kebesaran dan melebihi garis batas, lalu pada saat penerapan viewport untuk pengguna gadget yang header dan kontennya melebihi garis sehingga keluar garis batas dan mengotak-atik hingga menemukan perintah yang cocok untuk desain web, pada saat penerapan script.js lumayan sulit juga karena harus teliti untuk besar kecilnya huruf karena jika ada kesalahan dalam penulisan maka script.js tidak akan berfungsi dengan benar begitu juga dengan pada saat perubahan index.html ke index.php.
