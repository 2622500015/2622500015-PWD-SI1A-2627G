## Deskripsi Pertemuan-05
Pada pertemuan kelima Mendokumentasikan pengembangan JavaScript Dasar, DOM, Event dan Validasi Sisi Klien. 

### Materi yang dibahas:
1. **Menerapkan JavaScript Dasar untuk mengakses dan mengubah elemen DOM.**
2. **Menangani peristiwa pengguna menggunakan Event Listener.**
3. **Menerapkan Validasi Formulir Sisi Klien dan memberikan respon kepada pengguna.**
4. **Praktikum**
- Menguji interaksi, validasi, respon, mengidentifikasi galat debugging dengan Browser DevTools/Live Server, memperbaikinya, melakukan pengujian ulang serta mengelola kode dengan GitHub secara bertahap. 

### Tujuan Pembelajaran
- Mahasiswa mampu menerapkan JavaScript Dasar untuk mendukung interaksi pada halaman web.
- Mahasiswa mampu mengakses dan mengubah elemen HTML melalui Document Object Model (DOM).
- Mahasiswa mampu menangani peristiwa pengguna.
- Mahasiswa mampu menerapkan interaksi navigasi responsif (Hamburger Menu).
- Mahasiswa mampu menerapkan validasi formulir sisi klien berdasarkan aturan yang telah ditentukan.
- Mahasiswa mampu memberikan respon kepada pengguna baik ketika validasi gagal maupun ketika validasi berhasil, serta menghapus respon tersebut saat input berubah atau di reset.
