### Materi yang dibahas:
1. **Index.html, struktur dokumen HTML5, Semantic Elements vs Non-Semantic, pembuatan Hyperlink dan Image, Text Formatting, Validasi HTML, membangun Formulir menggunakan Elemen dan Tipe masukan sesuai kebutuhan data, menggunakan label serta atribut formulir, name, id, action, method, dan atribut validasi HTML sesuai kebutuhan formulir, menerapkan selector dan properti CSS dasar agar form tertata dan mudah dibaca.**
